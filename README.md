# E2E Login Test

Playwright and TypeScript end-to-end tests for registration, authentication,
account creation, and money transfers. The suite tests the application through
the browser and uses a small API helper to prepare users efficiently.

## Prerequisites

- Node.js 18 or later
- npm
- The frontend running at `http://localhost:3000`
- The API running at `http://localhost:6007`

## Quick start

```bash
npm install
npx playwright install
npm test
```

## How it works

1. `playwright.config.ts` discovers tests in `tests/` and configures the
   browser projects and HTML reporter.
2. Tests use Page Objects from `pages/` instead of repeating UI selectors.
3. Shared values are stored in `data/testData.json`; unique registration
   addresses are generated by `data/testData.ts`.
4. `tests/register.setup.ts` creates authenticated browser states in
   `.playwright/.auth/`.
5. Transaction tests reuse those states and exercise the dashboard.
6. Playwright writes reports and run artefacts to generated output directories.
